# 电脑UI收藏读取修复

电脑音乐库创建了独立的NeteaseSessionStore，却未刷新profile；即使侧栏已登录，该实例的userId仍为空，旧代码静默跳过请求并呈现空列表。另一个问题是所有收藏入口都调用snapshot，任意播放历史或歌曲详情失败都会使歌单也读取失败。

- 收藏歌曲/歌单先读取当前Cookie对应账号资料，失败显示实际错误与重试。
- 各入口独立读取：歌单只读用户歌单；收藏歌曲只读喜欢ID与分批歌曲详情；历史只读历史。
- 新增独立suspend入口，保留真实ID和喜欢列表顺序；相关HTTP调用绑定协程取消，切页/切账号取消请求。账号revision重置列表与详情状态，读取账号后校验会话未变。
- 不伪造收藏数据或登录状态，不将接口错误当空收藏。

验证：59 suites / 289 tests / 0 failures/errors/skipped，桌面编译通过。新增本地真实HTTP协议测试确认歌单不依赖歌曲/历史、收藏歌曲不依赖歌单/历史、空收藏不发详情请求、离开页面取消实际Call。协议测试仅使用明确fixture，不写应用账号。尚未使用私人账号独立验收真实收藏数量。
