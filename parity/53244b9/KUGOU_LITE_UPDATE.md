# 酷狗概念版迁移

以 Android 工作区的酷狗概念版实现为参考，Windows 新增独立的 `KugouLite` 音源和账号：概念版与标准酷狗分别使用自己的 appid、签名、设备标识、登录凭据及扫码入口，播放解析、目录、歌单和歌词走实际 provider 协议。Windows 账号存储使用现有安全偏好机制；账号切换后，迟到的播放授权、会员信息和设备标识不会覆盖新会话。

两套布局均有概念版会员和每日签到页面，应用启动可自动尝试两项实际奖励请求，结果按账号和日期保存；10 分钟冷却后仅重试当日尚未完成的奖励，手动操作仍由用户触发。响应明确标记为试听时，包含嵌套 `data` 的响应也不会被误判为完整播放。手机音乐服务页增加当前音源选择，标准／概念版服务入口分别打开各自登录表单；二维码加载时预留空间，避免按钮随结果出现而跳动。

使用隔离 home、实际鼠标／滚轮／键盘输入的四组本地回放通过：手机版 controls／reload 为 **25／7 scenes、19／5 assertions**，电脑版 controls／reload 为 **26／8 scenes、19／5 assertions**。覆盖独立登录表单、两种音源之间的实际切换、未登录时签到按钮禁用，以及自动签到开关在新 JVM 中重载。证据在 `evidence/kugou-lite/`；为避免传播临时扫码凭据，保留回放摘要及设置截图，不归档登录时可能含二维码的截图和语义文本。
