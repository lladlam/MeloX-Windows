# 液态玻璃开关外观／动画修复

用户反馈：拨动开关外观或动画异常。

## 定位与修改

- 基于固定 Android `53244b9` 的 `MeloXNativeGlassComponents.kt` 核对 64×28dp 轨道、40×24dp 滑块、20dp 行程及 2dp 水平内边距。
- 原滑块在 `CenterStart` 已垂直居中后又偏移 2dp，改为只施加水平位移，避免底边贴住轨道、上下留白不对称。
- 补回按压时只作用于玻璃采样的轨道变形：X 从 2/3 到 .75，Y 从 0 到 .75；真实轨道保持原尺寸，页面底图仍按真实位置采样。
- 原实现拖动中途禁用后会留下 `didDrag`，阻止回弹。真实指针回归在修改前复现“Disabling a switch during drag left its thumb between states”。现在取消未完成的拖动定位任务、清理拖动态并释放按压光学效果，恢复位置以外部 `checked` 为准。
- 连续拖动使用同步累计位置，不依赖异步动画上帧的数值；松手或取消时取消待执行的旧定位，避免旧任务覆盖回弹。
- 减少动态效果时直接恢复目标位置，关闭滑块拉伸和按压折射变形。

## 验证方式

扩展现有 `auditGlassOptics` 的生产开关指针回放，覆盖：点击、外部拒绝拖动后的回弹、拖动中途禁用／重新启用、取消后的第一次点击不得丢失或重复、滑块垂直居中及按压变形最终归零。沿用原三档密度（1／1.25／2）、深浅色、液态／磨砂组合和原生滤镜释放审计。

生成棋盘格仅作为光学底图；没有构造账号或播放业务。验证状态以实际审计结果为准。

## 本地结果

- 桌面编译及 `:desktop:auditGlassOptics` 通过，12 组配置均通过上述真实指针断言，玻璃采样／滤镜释放和原有弹窗回归通过。
- 失败基线、修复后日志、审计 JSON 及深浅色静止／按压／拒绝拖动／取消恢复截图保存在 `evidence/liquid-toggle-fix/`。
- 这是生产组件的实际光学和交互回归；固定 Android 像素逐点比对仍未完成，新 Windows 发行以对应 CI 和完整下载 ZIP 核验为准。
