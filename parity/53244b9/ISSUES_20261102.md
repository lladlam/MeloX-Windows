# GitHub Issues：导航、音量和收藏

- [#1 底部导航拖影](https://github.com/lladlam/MeloX-Windows/issues/1)：当前界面为原生 Compose，截图中的移动圆形来自玻璃选中层的拖动交互。移除底栏的拖动手势，保留标签点击和选中动画。Linux 生产 ImageComposeScene 的指针事件回放验证按住拖动不切换、点击两个标签仍可切换；深浅主题各 7 scenes / 10 assertions 通过。Windows 原生结果仍需验证。
- [#2 音量延迟](https://github.com/lladlam/MeloX-Windows/issues/2)：本地软件增益作用于输出前的 PCM，旧输出请求缓冲为 1 秒，普通解码的预处理块为 200 毫秒。请求缓冲调整为 100 毫秒、普通预处理块调整为 50 毫秒；双解码仍采用 20 毫秒块。受控 200 毫秒输出缓冲下，单、双解码的实际 PCM 测试验证静音在 300 毫秒位置前已生效，解码生命周期、AutoMix 集成和输出测试通过。驱动可能调整请求的缓冲；真实 Windows 设备的听觉延迟及稳定性尚需实机验证，远程 DLNA 音量不在本次本地 PCM 测试范围内。
- [#3 收藏按钮无反馈](https://github.com/lladlam/MeloX-Windows/issues/3)：播放器收藏初始读取和提交时显示进度；初始读取期间的点击会在读取结束后执行，失败显示实际错误，不支持的来源提供明确反馈。写入仍通过真实来源或统一收藏，成功后更新星标。Linux 生产 ImageComposeScene 的指针事件完成本地歌曲收藏及播放器操作回放（21 scenes / 35 assertions），独立进程重启后验证收藏恢复和取消（6 scenes / 11 assertions）；真实鼠标、私人在线账号及读取期间点击的 Windows 实机行为仍需验收。
