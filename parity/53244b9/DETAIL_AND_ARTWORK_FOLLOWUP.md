# 统一详情操作与竖屏封面续迁

固定源：Android `53244b9d6b21d7e3a609e8cb11876efef70f218b`，不跟随移动标签。

## 已接线

- canonical 歌曲列表详情的分享入口打开可滚动、可选中文本预览，复制调用真实系统剪贴板，失败显示实际错误。
- 真正网易云歌单分享正数真实歌单链接；provided songs 推荐列表、Provider 集合分享真实歌曲信息及已有公开歌曲链接，不把 UI summary ID 当作网易云歌单 ID。
- 更多入口提供详情信息、原始/歌曲/艺人/专辑排序；真实歌单支持重新加载，provided songs 不发起歌单刷新。
- 收藏态随真实 session revision 重新读取；读取期间未知，不沿用旧账户状态。收藏请求固定本次 Cookie，旧 revision 的结果不回写新账户；自己的歌单不显示取消订阅按钮。取消异常继续传播。
- 已有歌曲时，加载/写入错误也可见，避免只在空列表显示错误。

`ui/player/MeloXIOSNowPlayingSharedHost.kt`：

- 908–915：封面页到歌词/队列 header 本身使用 **480ms FastOutSlowIn**。此前把这一时间线列为“旧实现”不准确，保留它。
- 934–980、1644–1650：换歌 0.90→1 缩放、0.55→1 透明度；弹簧 ζ=0.42、k=480；AutoMix 过渡不重复叠加。

- 1158–1177：MiniPlay morph 期间按目标页封面姿态注册，避免还原歌词页时先展开大封面再缩成缩略图。

## 回放的实际边界

- Home 使用真实公开热歌榜，点开分享后核查真实歌曲链接，再真实点击排序并比较可见歌曲顺序。
- Player 使用生成的真实 WAV，经生产 FFmpeg 解码写软件 PCM；LRC 经生产 Local 扫描及持久歌词库后读取，必须出现实际 `lyric-line-*`。
- 修正前手机脚本只传 LRC 参数却没有 Local 扫描，因此此前截图的歌词页显示“暂无歌词”。此前通过数不证明歌词文档已显示。
- 歌词重开新增检查：保持 Lyrics 页、72dp 封面、22dp 顶部落点；中途帧也保持目标页封面尺寸。
- 首次新增回放在歌词重开后继续找队列按钮，遇到生产自动隐藏计时使按钮消失；调整操作顺序，先验证队列，再验证歌词重开，不改生产自动隐藏行为。
- 桌面回归改用各自独立 home；静态截图等待扩大到1200ms，避免把 queue inspector 仍滑入的中间帧当作258dp终态。原始650ms失败帧为251dp，未放宽几何容差。

系统剪贴板的可用性需原生桌面；离屏软件 PCM、指针回放不证明可听硬件、物理触屏或 Android 同内容像素一致。全量迁移保持 PARTIAL。
