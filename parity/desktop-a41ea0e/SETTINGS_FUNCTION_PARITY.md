# 桌面布局／手机版功能一致

用户要求：**设置仍为桌面UI布局，功能与手机版设置完全一致**。

- 保留五类桌面顶部标签、桌面窗口表面、分类子标签和紧凑控件；复用第一套布局的生产设置组件。
- 原先桌面和手机版各自维护的20个route分发合并为同一个 `SettingsRouteContent`；设置项、选项、条件显示、能力禁用、真实端点和持久化使用同一份实现。
- 桌面补齐手机版已有的设置搜索，使用相同标题／副标题／关键词和账户关键字；真实键盘搜索后点击结果进入桌面分类子页。
- 补齐重置播放器、退出登录入口，与手机版调用同一个 `SettingsAccountActions`；重置真实设置／播放模式／音质，退出清除真实会话。真实未登录状态不显示退出按钮。
- 修正桌面高级分类的长子标签横向溢出：子标签按可用宽度换行，避免“开发者／实验性”等实际入口被裁掉。
- `capture_settings_pages.py desktop-routes` 通过真实鼠标／滚轮访问全部20个桌面子页，检查重置与真实登录状态、键盘输入无匹配搜索；CI同时覆盖英文深色、中文浅色。

这里的“手机版”指本程序保留的第一套布局；平台能力限制沿用该布局的真实能力状态，不创建点击后无功能的替代开关。Windows原生触屏与有凭据的账户退出仍须相应真机／账户验收。
